# EIScape

This was my first game jam in University, a 5 person group project developed in 20 days.
## How To Play

Just Download the latest release and run .HTML.
## Open in Twine

Click on the blue "<>Code" dropdown and click "download zip".
Unzip the folder and put the .html and assets folder in the stories folder in the Twine folder.
