EIScape

An endless runner game assigned as a first project.

About

This was my first group project at University, we were tasked in making a simple game in a web based story telling program called Twine, the theme given was 'Time' and in total we had 20 days to complete.

Process

Art/Visuals: We wanted to keep a pixalated art style to it so all the images and text is consistent with this, the map was 3D modeled and screenshots of each area were used for the viewport.

Sound/Music: The SFX were found online, the music was made using Bandlab by one of our teammates and the AI voice was text-to-speech translated.

Code: Twine uses HTML, CSS and JavaScript to create the stories. I used a lot of online forums, YouTube videos and general googleing to help with writing all the code to put the game together..
